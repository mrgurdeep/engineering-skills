# jira-fix · Step 4/8 — Find the root cause

**Inputs:** failing test, code

**Do:**
1. Explain the cause in plain words with `file:line`; why it wasn't caught.
2. Impact: other callers, other projects via interdependency pages, data already affected.
3. Propose 1–2 fix options with risk; recommend one.

**Output:** root cause + options in `fix.md`

**Checkpoint ⏸ (wait for the user):** User approved the fix approach.
