# feature-build · Step 2/6 — Implement task by task

**Inputs:** next `T-n`, its `C-n`, AC and test cases

**Do:**
1. Smallest change that meets the task's done-check, with tests alongside (TDD where practical).
2. Run lint, type-check/build, scoped then full tests; commit `<JIRA-KEY>: <summary>` (no secrets, no unrelated refactors).
3. Log task, files, SHA, deviations. Design wrong or new gap → stop and ask; update `05-solution.md` after approval.
4. Repeat for each task; show progress after each.

**Output:** commits + log

**Checkpoint ⏸ (wait for the user):** All planned tasks committed with green checks.
